# Notebook

A personal portfolio of quant research notebooks. Here I take research questions and work through them in code: strategies built on real market data, results validated under honest assumptions, biases measured instead of hidden. Every number is reproducible from the notebook itself.

## Read it online

This repo is also published as a book at **https://luigi-mari.github.io/Notebook/**, with one page per chapter:

- [Naked Options Simulation in Python](https://luigi-mari.github.io/Notebook/optionspnl.html)
- [Nasdaq-100 Momentum Waterfall](https://luigi-mari.github.io/Notebook/nasdaq100_momentum_waterfall.html)
- [Robust Regression & Outlier Handling in Quantitative Finance](https://luigi-mari.github.io/Notebook/robust_outlier_handling.html)
